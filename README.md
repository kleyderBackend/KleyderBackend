> Plataforma fullstack de reservas turisticas que conecta turistas, hoteles y guias en un solo ecosistema

| Repo | Stack | Estado |
|------|-------|--------|
| [travel-go](https://github.com/kleyderBackend/travel-go) | `Next.js 14` `TypeScript` `Tailwind` `NextAuth` `Stripe` | En desarrollo |
| [travel-go-backend](https://github.com/kleyderBackend/travel-go-backend) | `NestJS` `PostgreSQL` `Prisma` `Redis` `Docker` | En desarrollo |
| [ksoft-technology](https://github.com/kleyderBackend/ksoft-technology) | `Next.js` `Node.js` `TypeScript` `React` | Activo |

- Turistas: buscar, comparar y reservar hoteles y guias
- Hoteles: gestion de inventario, precios y disponibilidad
- Guias: ofertar tours y gestionar calendario
- Admin: supervision, moderacion y reportes
